# 🍣 Sushiman - Japanese Food Delivery Website

A modern, responsive website for **Sushiman**, a Japanese food delivery service that brings authentic Japanese flavors right to your doorstep.

**Live Demo**: [Visit Sushiman](https://ezykl.github.io/sushiman/)

## 📁 Project Structure

```
sushiman/
├── index.html                 # Main HTML file
├── package.json              # Project dependencies
├── vite.config.js            # Vite configuration
├── public/                   # Static assets
├── src/
│   ├── main.js              # Main JavaScript entry point
│   ├── counter.js           # Counter component
│   ├── script.js            # Additional scripts
│   ├── css/
│   │   ├── style.css        # Main stylesheet
│   │   └── sections/        # Component-specific styles
│   │       ├── header.css
│   │       ├── hero.css
│   │       ├── about.css
│   │       ├── popular.css
│   │       ├── trending.css
│   │       ├── subscribe.css
│   │       └── footer.css
│   └── assets/              # Images and media
└── README.md                 # This file
```

## 🎓 Learning Outcomes

This project demonstrates:

- **HTML5 Semantic Markup** - Proper structure and accessibility
- **Advanced CSS** - Flexbox, Grid, responsive design, and modern layouts
- **JavaScript Fundamentals** - DOM manipulation and interactivity
- **Responsive Web Design** - Mobile-first approach with media queries
- **Web Performance** - Optimized assets and build configuration
- **Version Control** - Git workflow and GitHub integration
- **Web Deployment** - GitHub Pages deployment pipeline
